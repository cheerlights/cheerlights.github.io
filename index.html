CheerLights

Lights all over the world share one color. Anyone can change it, and every connected light follows.

On cheerlights.com

  • CheerLights websiteWhat CheerLights is, and the newest projects.
  • Learn page and APIHow to change the color, and how to read it from your own code.
  • Build a displayGuides for making a light that follows the color.
  • BlogProject write-ups, tutorials, and news.
  • DiscordSet the color, talk with other builders, and show what you made.

Set up a light

  • Install pageInstall the firmware on an ESP32 board with LEDs or a LilyGO T-Display, from Chrome or Edge on a computer. The light gets the color over Wi-Fi on its own, or from the CheerLights app for Android over Bluetooth.
  • Firmware sourceThe ESP32 firmware, its Wi-Fi API and Bluetooth profile, and the board presets.

Code on GitHub

  • Arduino libraryFetch the latest color over Wi-Fi in an Arduino sketch.
  • Python packageRead the live color, its history, and the palette. pip install cheerlights-api
  • MATLAB packageRead the live color, its history, and the palette in MATLAB.
  • JavaScript widgetsShow the current color on a web page.
  • MCP serverLet AI tools read the color through the Model Context Protocol.
  • Raspberry Pi Pico WConnect a Pico W to CheerLights.
  • CheerOrbsBuild a DIY CheerLights display and learn the basics of IoT.
  • CheerLights TerminalThe current color in ASCII art, in your terminal.

Everything else is at github.com/cheerlights.
