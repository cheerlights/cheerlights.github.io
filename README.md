# cheerlights.github.io

The page at [cheerlights.github.io](https://cheerlights.github.io/).
It links to the CheerLights website, docs, blog, and Discord, the install page for ESP32 lights, and the CheerLights code on GitHub.

It is plain HTML, CSS, and one script that shows the live CheerLights color, served by GitHub Pages from `master` with no build step.
To preview it, run `python -m http.server` in this folder and open http://localhost:8000/.
